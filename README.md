# Relic Layers Website

Public website for the mobile game **Relic Layers**: home page and the Privacy Policy in English and Polish.

- Live site: https://maciejniklas.github.io/Relic-Layers-Website/ (Privacy Policy: [EN](https://maciejniklas.github.io/Relic-Layers-Website/en/privacy/), [PL](https://maciejniklas.github.io/Relic-Layers-Website/pl/privacy/)).
- Site source: [`docs/`](docs/) — plain HTML/CSS, published with GitHub Pages from `main` / `docs`.
- Local preview: `python -m http.server 4173 -d docs`, then open http://localhost:4173/.
- Checks: `node tools/check-site.mjs` (Node 20+).
- Contributor and AI-agent instructions: [AGENTS.md](AGENTS.md) (Codex and Claude Code), [CLAUDE.md](CLAUDE.md).

The site sets no cookies and uses no analytics or third-party resources.
